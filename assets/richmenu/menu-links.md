## กับดักที่เคยเจอ ห้ามพลาดซ้ำ

**ปุ่มบนซ้ายชี้ไปที่การเพิ่มบัญชีทางการเป็นเพื่อน ไม่ใช่ลิงก์เชิญเข้ากลุ่ม**
เลือกแบบนี้ตั้งใจ เพราะกลุ่มเดียวที่ลงทะเบียนไว้ใน `line_targets` คือ
*กลุ่มแจ้งเตือนอุบัติเหตุ สภ.เมืองนครสวรรค์* ซึ่งรับข้อความแจ้งผู้เสียชีวิตพร้อมพิกัดอัตโนมัติ
ถ้าเอาลิงก์เชิญของกลุ่มนั้นมาแปะบนเมนูสาธารณะ ประชาชนจะเห็นเหตุเสียชีวิตก่อนญาติผู้ตาย
และใครก็เข้ามาป่วนกลุ่มที่เจ้าหน้าที่ใช้งานจริงได้
ถ้าวันหนึ่งอยากมีกลุ่มสำหรับประชาชนจริง ๆ ให้**สร้างกลุ่มใหม่แยก** อย่าใช้กลุ่มเดิม

**เบอร์โทรต้องเขียนติดกัน ห้ามมีขีดคั่น** `tel:055881567` ถ้าใส่ `tel:0-5688-1567` ไลน์จะตัดสายไม่ออก

**ลิงก์ e-Ticket ต้องมี `/eTicket/` ต่อท้าย** โดเมนเปล่า `ptm.police.go.th` เป็นหน้า Welcome to nginx
คนกดจะเจอหน้าขาวเปล่า ตรวจแล้วเมื่อ 21 ส.ค. 2569

**ลิงก์เชิญกลุ่มไลน์สร้างใหม่ได้ และเมื่อสร้างใหม่ ลิงก์เดิมจะตายเงียบ ๆ**
ไม่มีอะไรแจ้งเตือน ปุ่มจะยังกดได้แต่พาไปหน้าที่ใช้ไม่ได้
ถ้าวันหนึ่งเปลี่ยนไปใช้ลิงก์กลุ่ม อย่าไปกดสร้างลิงก์ใหม่หลังตั้งเมนูแล้ว

**รหัสกลุ่มกับลิงก์เชิญแปลงกลับไปมาไม่ได้** รหัสกลุ่มที่ขึ้นต้นด้วย `C` ได้จาก webhook ตอนบอทถูกเชิญเข้ากลุ่มเท่านั้น
ส่วนลิงก์เชิญ `line.me/R/ti/g/…` ได้จากในแอปเท่านั้น ไม่มี API ไหนแปลงอย่างหนึ่งเป็นอีกอย่างได้
