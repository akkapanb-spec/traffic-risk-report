# ต่อกล้องวงจรปิดเข้าระบบ

คู่มือทีละขั้น สำหรับกล้อง **TP-Link Tapo C246D** (สองเลนส์)

---

## ทำไมต้องมีเครื่องนี้

เบราว์เซอร์เล่น RTSP ไม่ได้ กล้องพูดได้แต่ RTSP จึงต้องมีตัวกลางแปลงเป็น HLS หรือ WebRTC ก่อน

ตัวกลางนั้นคือ **MediaMTX** — โปรแกรมเดียว ไฟล์เดียว ฟรี ไม่ต้องติดตั้ง

| ต้องมี | รายละเอียด |
|---|---|
| เครื่องเปิดตลอด | Mini PC / NUC / Raspberry Pi / เครื่องเก่าที่ไม่ใช้แล้ว ก็พอ |
| อยู่วง LAN เดียวกับกล้อง | RTSP ของ Tapo ออกนอกวงไม่ได้ |
| โดเมน + ใบรับรอง HTTPS | หน้าเว็บอยู่บน https ถ้าสตรีมเป็น http เบราว์เซอร์บล็อกทิ้ง |

# ส่วนที่ 1 — ตั้งค่าที่ตัวกล้อง

## ขั้นที่ 1 สร้างบัญชีกล้อง

**ไม่ทำข้อนี้ RTSP จะไม่เปิด** ไม่ว่าจะพยายามยังไงก็ต่อไม่ได้

แอป Tapo → เลือกกล้อง → ⚙️ → **Advanced Settings** → **Camera Account**

ตั้ง username และ password ยาว 6–32 ตัวอักษร

> ⚠️ **คนละอันกับบัญชี TP-Link ที่ใช้ล็อกอินแอป** เป็นบัญชีเฉพาะสำหรับให้โปรแกรมอื่นดึงภาพ

## ขั้นที่ 2 ล็อกเลข IP ของกล้อง

เข้าหน้าตั้งค่าเราเตอร์ → หา **DHCP Reservation** (บางยี่ห้อเรียก Address Reservation / Static Lease) → ผูก MAC ของกล้องกับ IP ที่ต้องการ

**ข้ามข้อนี้ไม่ได้** ไฟดับทีเดียว IP เปลี่ยน สตรีมดับหมดทุกกล้อง

จด IP ไว้ เช่น `192.168.1.50`

## ขั้นที่ 3 ทดสอบด้วย VLC ก่อนทำอย่างอื่น

ติดตั้ง VLC → **Media** → **Open Network Stream** → วางทีละอัน

```
rtsp://ชื่อผู้ใช้:รหัสผ่าน@192.168.1.50:554/stream1
```

```
rtsp://ชื่อผู้ใช้:รหัสผ่าน@192.168.1.50:554/stream6
```

| ควรเห็น | |
|---|---|
| `stream1` | ภาพมุมกว้าง 125° |
| `stream6` | ภาพจากเลนส์ซูม |

**ต้องเห็นทั้งสองอัน** ถ้า `stream6` ไม่มา ให้อัปเดตเฟิร์มแวร์กล้องก่อน แล้วลองใหม่

> 🛑 ถ้า VLC ยังเล่นไม่ได้ **หยุดตรงนี้** อย่าไปส่วนที่ 2 ปัญหาอยู่ที่กล้องหรือเครือข่าย ไม่ใช่ที่เกตเวย์

# ส่วนที่ 2 — ติดตั้งเกตเวย์

## ขั้นที่ 4 โหลด MediaMTX

โหลดจาก <https://github.com/bluenviron/mediamtx/releases> เลือกให้ตรงเครื่อง

| เครื่อง | เลือกไฟล์ที่ลงท้ายด้วย |
|---|---|
| Windows | `windows_amd64.zip` |
| Linux ทั่วไป | `linux_amd64.tar.gz` |
| Raspberry Pi | `linux_arm64v8.tar.gz` |

แตกไฟล์ออกมา จะได้ตัวโปรแกรมกับไฟล์ `mediamtx.yml`

## ขั้นที่ 5 เอาไฟล์ตั้งค่าของเราไปทับ

เอา `cctv/mediamtx.yml` จาก repo นี้ไปวางทับตัวที่มากับโปรแกรม

## ขั้นที่ 6 แก้ 3 จุดในไฟล์

เปิด `mediamtx.yml` ด้วย Notepad แล้วแก้

**6.1 วง IP ของหน่วย** — หาบรรทัด `192.168.1.0/24` แก้ให้ตรงกับวงจริง

**6.2 รายการกล้อง** — หาส่วน `paths:` แก้ IP กับ user/pass ให้ตรงกับที่ตั้งไว้ขั้นที่ 1–2

**6.3 ถ้ามีกล้องมากกว่าหนึ่งตัว** — ก็อป `cam1_wide` กับ `cam1_zoom` มาเป็น `cam2_...` แล้วแก้ IP

## ขั้นที่ 7 ใส่ใบรับรอง HTTPS

วางไฟล์ `server.crt` กับ `server.key` ไว้ในโฟลเดอร์เดียวกับตัวโปรแกรม

ยังไม่มีใบรับรอง ใช้ [Let's Encrypt](https://letsencrypt.org/) ได้ฟรี — ให้ฝ่าย IT ออกให้ หรือใช้ `certbot`

> **ทดสอบในวง LAN ก่อนได้** โดยแก้ `hlsEncryption` กับ `webrtcEncryption` เป็น `no` ชั่วคราว แต่**ห้ามใช้ค่านี้ตอนใช้งานจริง** เพราะหน้าเว็บ https จะบล็อกทิ้ง

## ขั้นที่ 8 สั่งรัน

**Windows** — ดับเบิลคลิก `mediamtx.exe`

**Linux / Raspberry Pi**

```bash
./mediamtx
```

ถ้าขึ้นบรรทัดที่มีคำว่า `[HLS] listener opened on :8888` แปลว่าใช้ได้

## ขั้นที่ 9 ทดสอบว่าออกมาเป็น HLS แล้วจริง

เปิด VLC อีกครั้ง วาง

```
https://ไอพีของเครื่องเกตเวย์:8888/cam1_wide/index.m3u8
```

เห็นภาพ = **เสร็จส่วนที่ยากที่สุดแล้ว**

## ขั้นที่ 10 ให้มันรันเองตอนเปิดเครื่อง

**Windows** — กด `Win + R` พิมพ์ `shell:startup` แล้วเอา shortcut ของ `mediamtx.exe` ไปวาง

**Linux** — สร้าง service ที่ `/etc/systemd/system/mediamtx.service`

```ini
[Unit]
Description=MediaMTX
After=network.target

[Service]
ExecStart=/opt/mediamtx/mediamtx
WorkingDirectory=/opt/mediamtx
Restart=always

[Install]
WantedBy=multi-user.target
```

แล้วสั่ง

```bash
sudo systemctl enable --now mediamtx
```

# แก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| VLC เล่น stream1 ไม่ได้ | ยังไม่ได้สร้าง Camera Account (ขั้นที่ 1) |
| `stream1` ได้ แต่ `stream6` ไม่ได้ | เฟิร์มแวร์กล้องเก่า ให้อัปเดตก่อน |
| หน้าเว็บขึ้นจอดำ แต่ VLC เล่นได้ | ใบรับรอง HTTPS ไม่ถูกต้อง หรือ IP เครื่องที่เปิดไม่อยู่ใน `ips` |
| ดูได้ที่โรงพัก ดูข้างนอกไม่ได้ | ถูกต้องแล้ว ตั้งใจให้เป็นแบบนั้น — ดูหัวข้อล่างสุด |
| ภาพกระตุก | ลดเหลือสตรีมคุณภาพต่ำ หรือแบนด์วิดท์ขาออกไม่พอ |

# ถ้าต้องดูจากนอกหน่วย

**อย่าแก้ `ips` เป็น `0.0.0.0/0`** นั่นเท่ากับเปิดกล้องให้คนทั้งโลกดู

ทางที่ถูกคือเปลี่ยนไปใช้ `authMethod: http` แล้วชี้ไปที่ตัวตรวจสอบ session ของระบบเจ้าหน้าที่ MediaMTX จะถามทุกครั้งก่อนปล่อยภาพ ว่า token นี้ยังใช้ได้ไหม

ต้องเขียนตัวรับเพิ่มอีกนิด บอกมาได้ตอนถึงขั้นนั้น

# ⚠️ เรื่องที่ต้องตัดสินใจก่อนเอาขึ้นหน้าประชาชน

ภาพกล้องเห็นหน้าคน ทะเบียนรถ พฤติกรรมบุคคล — **การเอาขึ้นหน้าสาธารณะคือการเผยแพร่ข้อมูลส่วนบุคคล มีประเด็น PDPA**

ต่างจากกล้องกรมทางหลวงใน `cctv.html` ที่กรมทางหลวงเป็นผู้เผยแพร่เอง และมุมกล้องออกแบบมาเพื่อดูสภาพจราจร

ระบบนี้จึงตั้งค่าให้กล้องของ สภ. **อยู่หลัง login ฝั่งเจ้าหน้าที่เท่านั้น** ถ้าจะเปิดสาธารณะ ควรพิจารณาเป็นกล้องต่อกล้องพร้อมหนังสืออนุมัติ

# เรื่องความปลอดภัยเครือข่าย

Tapo เป็นอุปกรณ์ระดับผู้ใช้ตามบ้าน และติดต่อกับคลาวด์ TP-Link ตลอดเวลา

**ควรแยก VLAN** ออกจากวงที่มีเครื่องงานคดี ให้กล้องคุยได้เฉพาะกับเกตเวย์กับอินเทอร์เน็ต ไม่ให้เห็นเครื่องอื่นในหน่วย
